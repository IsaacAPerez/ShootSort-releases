The verify sequence

Verified or it didn’t happen

Most copy tools write your files and hope. ShootSort treats every file as unproven until the drive itself says otherwise.

01

Copy to a temp file

Every file lands as a .partial first. Nothing ever exists half-written under its real name.

02

Hash while copying

A SHA-256 fingerprint is computed from the card’s bytes as they stream — no second read of your card.

03

Force to physical disk

The copy is flushed all the way to the SSD’s platters and cells — not left sitting in a write cache.

04

Read back and compare

ShootSort re-reads the copy from the drive, bypassing the cache, and compares fingerprints byte for byte.

05

Atomic rename

Only a proven copy gets its real name. If anything fails, the original is still safe on your card.
